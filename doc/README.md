# Financial History Book (주식 히스토리 차트)

이 프로젝트는 Yahoo Finance API를 연동하여 전 세계 주식 및 지수의 실제 가격 데이터를 시각화하고 비교하는 Flutter 기반의 금융 차트 애플리케이션입니다.

## 1. 프로젝트 목적
- 여러 종목의 주가 흐름을 동일한 시간축과 통화 기준으로 비교.
- 다양한 표시 단위(일/주/월/년) 및 기간 설정을 통한 다각도 분석 지원.
- 전 세계 거래소 데이터를 한글 태그와 함께 직관적으로 제공.

## 2. 주요 기능
- **실시간 종목 검색**: Yahoo Finance Search API를 통한 실시간 검색 (Debounce 적용).
- **글로벌 거래소 지원**: 코스피, 코스닥, 나스닥, 뉴욕, 런던, 도쿄 등 주요 거래소 배지 표시.
- **다중 종목 비교**: 최대 5개 슬롯에 종목을 추가하여 동시 비교 가능.
- **유연한 기간 설정**: 1개월~20년 및 사용자 직접 기간 선택(Date Range Picker) 지원.
- **표시 단위 변환**: 일, 주, 월, 년 단위로 데이터를 그룹화(Average Aggregation)하여 차트 렌더링.
- **통화 변환(Multi-Currency)**: 달러, 원화, 유로 간의 자동 환율 변환 및 Y축 단위 적용.
- **통신 로그 창**: 서버 요청 및 응답 상태를 실시간으로 모니터링.
- **웹 호환성**: CORS 이슈 해결을 위한 AllOrigins 프록시 서버 연동.

## 3. 코드 구조 설명
- `lib/main.dart`: 메인 UI 구성, 상태 관리 및 차트 렌더링 로직 포함.
- `lib/models/stock_model.dart`: `Stock` (종목 정보), `StockDataPoint` (가격 데이터) 모델 정의.
- `lib/services/finance_service.dart`: API 요청, 프록시 처리, 헤더 설정 등 네트워크 서비스 레이어.
- `doc/`: 프로젝트 문서화 파일 저장.

## 4. 향후 확장 가능성 (To-Do)
- **실시간 환율 연동**: 현재 고정 환율을 실제 환율 API 연동으로 교체.
- **로컬 저장소(Persistence)**: 사용자가 선택한 종목 리스트를 앱 재시작 시에도 유지.
- **기술적 지표 추가**: 이동평균선(MA), 볼린저 밴드 등 차트 오버레이 기능.
- **다크 모드 지원**: 사용자 경험 개선을 위한 테마 최적화.
- **내보내기 기능**: 차트 이미지 저장 또는 CSV 데이터 추출.
